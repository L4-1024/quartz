## 文字是线性的，灵感是网状的

![[canvas-layout.png|Canvas 布局示意]]

传统的笔记形式是线性的——一行一行，一段一段。但我们的思维往往是**网状的**，一个灵感触发另一个，跳跃式连接。

Canvas（画布）就是 Obsidian 提供的白板功能，让你的知识库像乐高一样动起来。

---

## Canvas 是什么？

Canvas 是 Obsidian v1.5+ 内置的白板功能，不需要安装额外插件。

你可以在一个无限大的画布上：
- 添加文字卡片
- 放置图片
- 嵌入笔记
- 绘制连接线
- 自由排布组合

---

## 创建 Canvas

### 方式一：命令面板

1. `Ctrl/Cmd + P` 打开命令面板
2. 输入 "canvas"
3. 选择"新建画布"

### 方式二：右键菜单

在文件管理器中右键 → "新建画布"

### 方式三：快捷键

设置 `Ctrl/Cmd + N` 新建时选择"画布"

---

## Canvas 基本操作

### 添加内容卡片

1. 在画布空白处双击
2. 选择卡片类型：
   - **文字卡片**：纯文本
   - **笔记卡片**：嵌入已有笔记
   - **图片卡片**：添加图片
   - **链接卡片**：添加外部链接

### 移动和缩放

- **拖拽**：按住鼠标拖动画布空白区域
- **缩放**：使用 Ctrl/Cmd + 滚轮
- **选中**：点击卡片，按住 Shift 多选
- **框选**：在空白处拖拽创建选框

### 连接线

1. 选中一个卡片
2. 拖拽卡片边缘的圆点
3. 连接到另一个卡片
4. 可以设置连接线样式（直线、曲线、箭头）

---

## 卡片内容编辑

### 文字卡片

双击进入编辑模式，支持完整的 Markdown 语法。

### 笔记卡片

- 右键卡片 → "关联文件" → 选择笔记
- 或直接拖拽笔记到画布
- 笔记卡片会实时显示笔记内容预览

### 卡片样式

右键卡片可以设置：
- 背景颜色
- 边框样式
- 文字颜色
- 卡片大小

---

## Canvas 布局技巧

### 1. 自由布局

适合头脑风暴、灵感收集阶段，不做任何整理。

### 2. 分区布局

用颜色区分不同区域：

```
┌─────────────┬─────────────┐
│   想法 A    │   想法 B    │
├─────────────┼─────────────┤
│   想法 C    │   想法 D    │
└─────────────┴─────────────┘
```

### 3. 流程图布局

用连接线表示流程关系：

```
[A] → [B] → [C]
  ↓         ↓
[D]     [E]
```

---

## Canvas 最佳实践

### 1. 不要过度设计

Canvas 的价值在于灵活性，不要花太多时间在排版上。

### 2. 及时整理归档

Canvas 适合初期发散，后续应将内容整理到正式笔记中。

### 3. 善用分组

使用背景色或边框将相关内容分组。

### 4. 配合笔记使用

Canvas 不是替代笔记，而是笔记的补充工具。

---

## Excalidraw：更强大的画布插件

如果 Canvas 功能不够用，可以安装 **Excalidraw** 社区插件。

### Excalidraw 特点

- 手绘风格的图形
- 更丰富的绘图工具
- 与 Obsidian 笔记深度集成
- 支持导出为图片

### 安装 Excalidraw

1. 通过“第三方插件安装”一文里的方法安装
2. 仓库：`https://github.com/zsviczian/obsidian-excalidraw-plugin`

### Excalidraw 基础操作

1. 创建 Excalidraw 画布：`Ctrl/Cmd + P` → "Excalidraw"
2. 使用工具栏绘制图形
3. 文字工具添加标注
4. 拖拽调整位置

## 常见问题

**Q：Canvas 会自动保存吗？**

A：会，像普通笔记一样自动保存。

**Q：Canvas 支持实时协作吗？**

A：目前不支持，需要通过 Obsidian Sync 或第三方同步工具。

**Q：Canvas 笔记太多会卡吗？**

A：大量卡片可能会影响性能，建议及时整理归档。
