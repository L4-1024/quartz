## 任务基础语法

Obsidian 使用 Markdown 复选框语法管理任务：

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
- [-] 已取消/无效的任务
```

### 任务状态

| 语法 | 状态 | 说明 |
|------|------|------|
| `[ ]` | 待办 | 需要完成 |
| `[/]` | 进行中 | 正在处理 |
| `[x]` | 已完成 | 任务完成 |
| `[-]` | 取消 | 无效/取消 |
| `!>` | 重要 | 标记重要 |
| `?>` | 问题 | 有疑问 |

---

## 插入任务

### 方式一：手动输入

```markdown
- [ ] 这是一个待办任务
```

### 方式二：快捷键

1. 在编辑行输入文字
2. `Ctrl/Cmd + Enter` 插入复选框
3. 自动转换为 `[ ] 文字`

### 方式三：命令面板

1. `Ctrl/Cmd + P`
2. 输入"任务"
3. 选择相关命令

## 任务与标签结合

### 为任务添加上下文

```markdown
- [ ] 完成项目报告 #工作 #周报 #重要
- [ ] 购买食材 #生活 #购物
```

### 任务语法在标签前后均可

```markdown
# 都可以
- [ ] #工作 任务1
- [ ] 任务2 #工作
```

## 进阶：使用 Dataview 汇总任务

![[task-dashboard.png|任务看板示意图]]

安装 **Dataview** 插件后，可以创建任务汇总看板。

### 汇总所有待办

```markdown
## 使用时候替换为dataview块
TASK
FROM ""
WHERE !completed
SORT file.ctime DESC
```

### 汇总特定标签的任务

```markdown
## 使用时候替换为dataview块

TASK
FROM ""
WHERE contains(file.tags, "工作")
WHERE !completed
```

### 按项目分组

```markdown
## 使用时候替换为dataview块
TASK
FROM ""
WHERE !completed
GROUP BY project
```

如果你已经在 frontmatter 中维护了 `project`、`status`、`review_cycle` 等字段，Dataview 汇总会更稳定。任务本身负责记录动作，属性字段负责提供筛选维度，两者结合后更适合做项目看板和周期回顾。

## 项目任务模板

创建一个专门的任务笔记模板：

```markdown
---
type: project-task
project:
status: 进行中
tags: [任务, 项目]
---

# {{title}} - 项目任务

## 任务列表

### 待完成
- [ ] 子任务 1
- [ ] 子任务 2

### 已完成
- [x] 已完成的任务

### 阻塞中
- [ ] 等待外部依赖

## 进度追踪

完成度：1/3

## 相关背景
- 项目主笔记
```

## 任务管理最佳实践

### 1. 每日回顾

每天打开 Daily Note 时：
- 检查未完成的任务
- 标记当日完成的任务
- 添加新任务

### 2. 任务分层

```
项目 A
├── 阶段一
│   ├── 任务 1
│   └── 任务 2
└── 阶段二
    └── 任务 3
```

### 3. 设置截止日期

在任务旁添加截止日期：

```markdown
- [ ] 完成报告 ⏳ 2024-01-20
- [ ] 跟进客户 ⏳ 2024-01-25
```

### 4. 定期清理

每周/月检查任务列表：
- 删除无效任务
- 延期长期未完成的任务
- 拆分过大的任务

## 常见问题

**Q：任务会自动同步到任务列表吗？**

A：Obsidian 没有内置的任务中心，需使用 Dataview 插件创建汇总视图。

**Q：可以设置提醒吗？**

A：Obsidian 本身不支持提醒，可配合手机 App 或系统通知实现。

**Q：已完成的任务会自动归档吗？**

A：不会，需要手动移动或整理。
