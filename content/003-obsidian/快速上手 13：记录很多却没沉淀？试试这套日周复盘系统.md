# 快速上手 13：记录很多却没沉淀？试试这套日周复盘系统

![[review-system.png|日周复盘系统封面]]

> 适读人群：希望把记录沉淀为周期性回顾习惯的读者
> 
> 阅读收获：搭建可持续执行的日复盘与周复盘框架

## 工具不需要多，需要的是把工具串起来

![[review-templates.png|复盘模板结构示意]]

用 Obsidian 自带的 Calendar、模板和搜索，三件套就能跑通一套日周复盘习惯。

---

## 三件套介绍

| 工具 | 作用 | 对应插件/功能 |
|------|------|---------------|
| Calendar | 日记入口 | 核心插件 |
| 模板 | 结构化内容 | 核心插件 |
| 搜索 | 汇总回顾 | 核心功能 |

---

## 日复盘：每日日记

### 每日日记模板

```markdown
---
created: {{date}}
type: daily
tags: [日记, 日复盘]
---

# {{date:YYYY-MM-DD}} 日复盘

## 今日三件事
- [ ]

## 收获
1.
2.
3.

## 反思
- 做得好的：
- 需要改进的：

## 明日计划
- [ ]
```

### 工作流

```
早上 → 打开 Calendar → 查看今日任务
     → 填写"今日计划"

晚上 → 打开日记
     → 填写"今日三件事"
     → 填写"收获"和"反思"
     → 规划明日任务
```

## 三件套联动

![[review-weekly-loop.png|周复盘循环流程图]]

### Step 1：每日记录（Calendar + 模板）

1. 打开 Calendar，点击今天日期
2. 日记模板自动创建
3. 填写三件事、收获、反思

### Step 2：每周汇总（搜索）

1. 打开搜索 `Ctrl/Cmd + Shift + F`
2. 搜索本周日记

```
path:Daily AND created:2024-01-15 to 2024-01-21
```

3. 汇总本周的关键收获和问题

### Step 3：周记创建（模板）

1. 基于周复盘模板创建周记
2. 引用本周日记
3. 完成系统性复盘

## 复盘模板索引

在 `_templates` 文件夹中创建 `复盘模板索引.md`：

```markdown
# 复盘模板

## 每日复盘
文件：`_daily.md`
位置：`Daily/YYYY-MM-DD.md`

## 每周复盘
文件：`周复盘.md`
位置：`Review/Weekly/`

## 每月复盘
文件：`月复盘.md`
位置：`Review/Monthly/`
```

## 复盘习惯养成

### 1. 固定时间

| 复盘类型 | 推荐时间 |
|----------|----------|
| 日复盘 | 睡前 10 分钟 |
| 周复盘 | 周五下午或周日晚上 |
| 月复盘 | 每月最后一天 |

### 2. 从小开始

不要追求完美，先从最简单的模板开始：
- 日记：今天三件事
- 周记：本周完成的三件事

### 3. 可视化追踪

使用 Dataview 统计复盘完成情况：

```dataview
TABLE file.ctime as "日期"
FROM "Daily"
WHERE type = "daily"
WHERE contains(tags, "日复盘")
SORT file.ctime DESC
LIMIT 30
```

## 常见问题

**Q：每天写日记太耗时？**

A：先从 3 句话开始，不要追求完美。

**Q：周记如何快速汇总日记内容？**

A：使用搜索过滤本周日记，逐篇回顾关键点。

**Q：模板太复杂不想用？**

A：简化模板，只保留最必要的字段。
