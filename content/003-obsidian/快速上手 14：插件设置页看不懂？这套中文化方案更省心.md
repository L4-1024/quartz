## I18N 插件简介

I18N（Internationalization）插件是专门为中文用户打造的插件汉化工具，可以将插件的设置界面翻译成中文。

### 核心特点

- 支持云端翻译词典
- 无需配置 AI 或 API Key
- 安装即用
- 支持大多数主流插件

---

## 安装 I18N 插件

### 方式一：插件市场安装

1. `设置 → 第三方插件`
2. 关闭"安全模式"
3. 搜索 "obsidian-i18n"
4. 安装并启用

### 方式二：手动安装

1. 下载插件文件：
   - `main.js`
   - `manifest.json`
   - `style.css`

2. 创建插件目录：
   ```
   .obsidian/plugins/obsidian-i18n/
   ```

3. 复制文件到该目录
4. 重启 Obsidian
5. 在插件列表中启用

### 仓库地址

```
https://github.com/eondrcode/obsidian-i18n
```

---

## 配置 I18N 插件

### 基础配置步骤

1. **启用插件**
   - 在插件列表中找到 "I18N"
   - 点击启用

2. **选择目标语言**
   - 设置 → 插件设置 → I18N
   - 目标语言：`zh-cn`（简体中文）

3. **选择工作模式**
   - 本地文件模式（默认）
   - 云端模式（需要网络）

### 推荐配置

```yaml
目标语言: zh-cn
工作模式: 本地文件模式
智能更新: 开启
翻译来源: 云端共享词典
```

---

## 云端模式 vs 本地模式

![[i18n-mode-choice.png|I18N 模式选择示意]]

| 模式 | 优点 | 缺点 |
|------|------|------|
| 本地模式 | 无需网络，离线可用 | 词典可能不完整 |
| 云端模式 | 词典实时更新，更完整 | 需要网络连接 |

### 切换模式

1. `设置 → 插件设置 → I18N`
2. 找到"工作模式"选项
3. 切换为"本地文件模式"或"云端模式"

选择建议：

- 需要稳定离线使用时，优先本地模式
- 希望优先获得较新的词条覆盖时，优先云端模式
- 如果云端模式加载较慢，可以先切回本地模式完成设置，再按需切换

## 常见问题

**Q：启用后界面没有变成中文？**

A：
1. 检查目标语言是否设置为 `zh-cn`
2. 重启 Obsidian
3. 检查网络连接（云端模式）
4. 等待 10 秒让词典加载

**Q：某些插件没有翻译？**

A：I18N 插件依赖社区贡献词典，可能部分插件暂未支持。

**Q：如何更新词典？**

A：云端模式下词典会自动更新；本地模式需要等待插件更新。

**Q：可以参与词典贡献吗？**

A：可以，访问 GitHub 仓库参与贡献翻译。
