## 一、什么是 Obsidian + Marp

![[marp-workflow.png|Marp 幻灯片制作流程图]]

### 1.1 什么是 Obsidian？

**Obsidian** 是一款以 Markdown 为核心、基于本地文件夹的知识库管理工具。它致力于构建结构化的个人知识网络，让知识的积累与连接变得前所未有的简单。

**核心特点**：

| 特性          | 说明                          |
| ----------- | --------------------------- |
| **双向链接网络**  | 打破孤岛，自动发现笔记间的隐性关联，构建网状知识结构  |
| **可视化图谱视图** | 以全局视角直观展示知识节点的分布与连接，让结构一目了然 |
| **强大插件生态**  | 社区驱动的海量插件，支持自定义工作流，扩展无限可能   |
| **本地优先架构**  | 数据即文件，纯文本存储，完全掌控数据所有权，安全且开放 |

### 1.2 什么是 Marp？

**Marp** 是一个开源的幻灯片制作工具，它允许用户使用简洁的 Markdown 语法来编写幻灯片内容，让创作回归内容本身。

| 特性              | 说明                            |
| --------------- | ----------------------------- |
| **Markdown 驱动** | 专注内容创作，告别繁琐的界面操作              |
| **多格式导出**        | 可导出 PDF、PPTX、HTML 等专业格式            |
| **全平台支持**       | 完美适配 Windows, macOS, Linux 系统 |
| **开源社区驱动**      | 完全免费，拥有活跃的全球开发者社区             |

> **核心价值**：将重心完全放在内容上，实现高效优雅的制作体验。

### 1.3 为何选择 Obsidian + Marp？

将 Obsidian 的知识管理能力与 Marp 的幻灯片生成能力结合，创造出无缝、高效且高度集成的知识工作流。

| 优势              | 说明                                    |
| --------------- | ------------------------------------- |
| **工作流统一**       | 在同一个应用内完成笔记、研究到幻灯片制作，无需频繁切换软件         |
| **Markdown 原生** | 使用熟悉的 Markdown 语法，学习成本低，内容编辑效率极高      |
| **知识库集成**       | 幻灯片可直接双向链接到知识库笔记，实现内容的动态关联与复用         |
| **版本控制友好**      | 纯文本 Markdown 文件，可轻松使用 Git 进行历史回溯和团队协作 |
| **高度可定制**       | 通过自定义 CSS 主题和配置，完全掌控幻灯片的视觉风格与细节       |

## 二、安装配置

### 2.1 插件选择

市面上有两个主要的 Marp 相关插件可供选择：

#### 插件一：Marp Slides (by Samuele Cozzi)

**核心优势**：

- 社区最活跃，文档完善
- 支持实时预览
- 深度主题定制
- 多种格式导出

**使用限制**：

- 导出 PDF/PPT 需本地安装 Chrome/Edge
- 不支持 Obsidian 原生 WikiLink

✅ **推荐首选**：成熟稳定，综合体验最佳

#### 插件二：Marp (by JichouP)

**核心优势**：

- 完美支持 Obsidian WikiLink 语法
- 方便直接引用库内的笔记和图片资源

**使用限制**：

- 高级导出功能依赖 Node.js 环境配置
- 功能更新较慢，文档相对简陋

⚡ **备选方案**：重度依赖 WikiLink 时使用

> 本指南后续章节将以 **Marp Slides 插件**为例，详细介绍从安装、主题配置到最终导出的完整工作流。

### 2.2 安装步骤

#### 核心安装流程

1. 打开 Obsidian 设置面板
2. 进入「社区插件」选项
3. 关闭「限制模式」开关
4. 点击「Browse」浏览插件
5. 搜索 "Marp Slides"
6. 找到插件并点击 Install
7. 安装完成后点击 Enable

#### 关键路径配置

安装完成后，建议配置以下关键设置：

| 设置项             | 说明                   |
| --------------- | -------------------- |
| **主题文件夹路径**     | 指定 CSS 文件存放位置        |
| **Chrome 执行路径** | 指定浏览器 exe 文件位置（用于导出） |
| **默认主题**        | 设置默认使用的幻灯片主题         |
| **默认尺寸**        | 设置默认幻灯片尺寸（如 16:9）    |

## 三、核心语法

### 3.1 创建你的第一张幻灯片

````markdown
---
marp: true
theme: default
size: 16:9
paginate: true
---

# 我的第一张幻灯片

## 第二页：核心要点

```python
print("Hello, Marp!")
````

````

#### YAML 前置元数据

在文件最开头定义全局属性，例如启用 Marp 渲染引擎、指定幻灯片主题、设置屏幕尺寸等，是幻灯片的"总开关"。

常用配置项：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `marp` | 启用 Marp 渲染 | `marp: true` |
| `theme` | 指定主题 | `theme: default` 或 `theme: gaia` |
| `size` | 幻灯片尺寸 | `size: 16:9` 或 `size: 4:3` |
| `paginate` | 是否显示页码 | `paginate: true` |
| `header` | 页头内容 | `header: "演示文稿标题"` |
| `footer` | 页脚内容 | `footer: "第 _PAGENO_ 页"` |

#### 幻灯片分隔符

使用单独一行的 `---` (三个连字符) 来分割不同的幻灯片页面。这是划分内容层级最简洁的语法。

### 3.2 核心语法详解

#### 幻灯片分隔符

**语法**：`---`

**核心作用**：在新的一行单独使用三个连字符，用于快速创建一个全新的幻灯片页面。

```markdown
# 第一页

---

# 第二页
````

#### 演讲者备注

**语法**：`[这里是备注内容]`

**核心作用**：方括号包裹的内容将作为私密的演讲者备注，在实际演示时观众不可见。

**示例**：

```markdown
# 我的演讲要点

[这里是演讲者备注内容，观众看不到]
```

#### 自动缩放标题

**语法**：`<!-- fit -->`

**核心作用**：在标题后添加此特殊注释，系统将自动调整标题字号，使其完美适应页面宽度。

**示例**：

```markdown
# 超长标题内容 <!-- fit -->
```

### 3.3 标准 Markdown 语法支持

Marp 完全支持标准 Markdown 语法：

#### 多级标题定义

使用 `#`, `##`, `###` 等符号，快速定义文档层级结构

```markdown
# 一级标题
## 二级标题
### 三级标题
```

#### 灵活的列表排版

支持 `-`/`*`/`+` 无序列表与 `1.`/`2.` 有序列表，条理清晰

```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

#### 文本样式修饰

粗体 `**` 与 斜体 `*` 组合使用，重点内容一目了然

```markdown
**粗体文本**
*斜体文本*
```

#### 资源嵌入与链接

支持 `[文本](URL)` 链接与标准图片语法，丰富内容展示

```markdown
[链接文字](https://example.com)

![图片描述](image.jpg)
```

> 提示：暂不支持 Obsidian 的 WikiLink 图片格式（如 `![[image.jpg]]`）

## 四、进阶技巧

### 4.1 主题定制

Marp 的一大魅力在于其高度可定制性。通过编写 CSS 文件，你可以完全掌控幻灯片的字体、颜色与布局，创建独一无二的专属主题。

#### 主题定制步骤

1. **创建主题文件夹**：在 Obsidian 库中新建目录（如 `MarpThemes`）
2. **配置插件路径**：在设置中指定 `Theme Folder Location` 为此路径
3. **新建 CSS 文件**：在文件夹中创建样式文件（如 `my-theme.css`）
4. **引用主题配置**：在 YAML 头部添加 `theme: my-theme` 以启用自定义样式
5. **编写样式规则**：编写 CSS 定制字体、颜色等视觉细节

#### 简单的自定义主题示例

```css
/* my-theme.css */
section {
    font-family: "PingFang SC", "Microsoft YaHei", sans-serif;
    background-color: #f8f9fa;
}

h1 {
    color: #2c3e50;
    border-bottom: 3px solid #3498db;
}

h2 {
    color: #3498db;
}

code {
    background-color: #e8e8e8;
    padding: 2px 6px;
    border-radius: 4px;
}
```

在幻灯片中引用：

```markdown
---
marp: true
theme: my-theme
---
```
### 4.2 更多探索

#### 背景图片定制

Marp 支持为单页或全局幻灯片设置背景图片，让演示文稿的视觉表现力更上一层楼。

**语法**：

```markdown
---
marp: true
backgroundImage: url('background.jpg')
backgroundSize: cover
---

# 带背景的幻灯片
```

或者针对单页：

```markdown
![bg](image.jpg)

# 单页背景
```

💡 建议探索方向：搜索 "Marpit markdown background image" 查阅官方文档。

#### 图表可视化支持

虽然 Marp 核心不直接支持 Mermaid，但可以通过安装插件或特定配置，实现代码块渲染图表的功能。

💡 建议探索方向：搜索 "Marp mermaid support"，或前往 Obsidian 社区寻找结合 Mermaid 与 Marp 的成熟插件方案。

✨ 技术社区非常活跃，遇到问题时，查阅文档或社区通常能找到满意的解决方案。

## 五、导出与分享

### 5.1 导出操作流程

1. **打开笔记**：在 Obsidian 编辑器中打开你的幻灯片笔记文件
2. **启动预览**：在右侧边栏找到并点击 `Marp Slides` 图标
3. **执行导出**：在预览窗口右上角菜单中，选择 `Export` 选项
4. **选择格式**：在弹出的对话框中，选择你需要的输出格式

### 5.2 支持的导出格式

| 格式       | 说明                         | 适用场景           |
| -------- | -------------------------- | -------------- |
| **PDF**  | 最通用的格式，完整保留所有排版与样式         | 正式演示、分享文档      |
| **PPTX** | 导出为微软 PowerPoint 格式，方便二次编辑 | 需要在 PPT 中调整的场景 |
| **HTML** | 导出为网页格式，体积小巧               | 在线分享、嵌入网页      |
| **图片序列** | 将每一页导出为独立的图片文件（PNG/JPG）    | 社交媒体分享         |

> **导出前提**：需本地安装 Google Chrome、Chromium 或 Microsoft Edge 浏览器作为渲染引擎。

### 5.3 演示模式

除了导出，Marp Slides 还支持直接在浏览器中进行演示：

1. 在预览窗口右上角菜单中选择 `Open in Browser`
2. 浏览器将打开演示视图
3. 支持键盘快捷键：
   - `←` / `→`：翻页
   - `F`：全屏模式
   - `S`：演讲者视图（显示备注）
