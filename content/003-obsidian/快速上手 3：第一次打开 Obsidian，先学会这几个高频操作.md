## 创建笔记的几种方式

![[editor-layout.png|Obsidian 编辑器界面布局]]

### 方式一：快捷键创建

| 快捷键 | 系统 |
|--------|------|
| `Ctrl + N` | Windows/Linux |
| `Cmd + N` | macOS |

### 方式二：快速切换器

按 `Ctrl + O`（Windows）或 `Cmd + O`（macOS），输入文件名后按回车即可创建并打开新笔记。

### 方式三：内部链接创建

在任意笔记中输入一个新的笔记标题，点击后即可创建并打开该笔记。

### 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 格式

```markdown
**粗体**
*斜体*
~~删除线~~
`行内代码`
```

### 列表

```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

### 待办事项

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
```

## 表格

### 基础表格

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
| D   | E   | F   |
```

### 效果

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| A   | B   | C   |
| D   | E   | F   |

对齐：`|:----|` 左对齐 `|:---:|` 居中 `|----:|` 右对齐

### 表格常用场景

| 场景 | 示例 |
|------|------|
| 人物介绍 | 姓名、职位、部门 |
| 进度追踪 | 项目、状态、完成度 |
| 读书清单 | 书名、作者、阅读状态 |

### 表格内使用格式

```markdown
| 功能 | 链接 |
| --- | --- |
| 快速上手指南 | 模板插件使用说明 |

| 项目 | 截图 |
| --- | --- |
| 界面展示 | 插入截图并控制宽度为 200 |
```

详细表格语法可参考 [Markdown 官方表格语法](https://www.markdownguide.org/extended-syntax/#tables)。

## 养成笔记习惯

### 笔记的黄金法则

| 法则 | 说明 |
|------|------|
| 先记下来，再优化 | 灵感闪现时，立即记录。可以粗糙，但一定要快 |
| 少即是多 | 碎片化的想法、一句话的灵感都是有效的笔记 |
| 链接比文件夹更灵活 | 避免创建过深的文件夹层级，优先使用内部链接和 `#标签` |

### 快速添加笔记

1. `Ctrl + N` 创建新笔记
2. 标题格式建议：`YYYY-MM-DD 灵感关键词`
3. 内容尽量简短，一页一个想法

### 定期整理

建议每周抽出 30 分钟：

1. 搜索近期碎片笔记
2. 将相关笔记链接合并
3. 删除不再需要的临时记录

### 心态调整

- **不要追求完美** - 笔记是给自己看的，你放心AI能够后续加工好，最担心的就是缺少带个人特点和理解的原材料。
- **不要过度分类** - 链接比文件夹更强大，有了AI可以做到全局看起来合理的分类
- **坚持记录** - 哪怕每天只写一句话，贴近现实的原材料是第一生产力。
