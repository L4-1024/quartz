# 快速上手 4：双链、反链、搜索怎么配合用？一次讲透

![[links-search.png|链接、反向链接与搜索封面]]

> 适读人群：希望把笔记从单篇记录升级为可检索知识网络的读者
> 
> 阅读收获：同时掌握双链、反向链接、搜索入口和常用检索语法

## 为什么把链接和搜索放在一起

![[search-operators.png|Obsidian 搜索操作符示意]]

在 Obsidian 中，链接负责建立知识之间的关系，搜索负责在关系网络中快速定位内容。把这两部分一起掌握，才能真正提高笔记的可用性。

## 一、内部链接

### 基础链接

使用双括号创建指向其他笔记的链接：

```markdown
这是一段文字，指向 [[另一篇笔记]]。
```

### 链接到特定标题

```markdown
查看 [[另一篇笔记#第二章]] 的内容。
```

### 链接到特定段落

```markdown
这是对特定段落的引用 [[另一篇笔记#^abc123]]。
```

### 嵌入内容

```markdown
![[被嵌入的笔记]]
```

常见用途：

- 将长笔记拆分为多个主题页
- 在日记中嵌入固定模板内容
- 在总览页中引用摘要或行动清单

## 二、反向链接

当笔记 A 链接到笔记 B 时，笔记 B 会自动显示被哪些页面引用，这就是反向链接。

### 查看方式

1. 打开目标笔记
2. 在右侧边栏查看“反向链接”面板
3. 根据引用上下文判断这篇笔记与哪些主题相关

### 适用价值

- 发现被频繁引用但尚未系统整理的主题
- 找到知识网络中的关键节点
- 补齐孤立页面与缺失链接

## 三、三个核心搜索入口

### 1. 快速切换器 `Ctrl/Cmd + O`

适合记得文件名或主题名时快速打开笔记。

### 2. 当前文件搜索 `Ctrl/Cmd + F`

适合在单篇长文中定位某个段落、术语或配置项。

### 3. 全局搜索 `Ctrl/Cmd + Shift + F`

适合在整个库中查找关键词、标签、路径和任务。

## 四、常用搜索语法

![[search-syntax-map.png|搜索语法结构图]]

### 关键词与精确匹配

```markdown
关键词
"精确短语"
```

### 文件名搜索

```markdown
file:报告
file:*会议*
```

### 路径搜索

```markdown
path:日记/2024
path:-归档
```

### 标签搜索

```markdown
tag:#工作
tag:#工作/项目A
```

### 链接关系搜索

```markdown
inlinks:[[某个主题]]
outlinks:[[某个主题]]
```

### 时间与组合搜索

```markdown
created:this-week
modified:today
tag:#工作 AND file:周报
```

## 五、进阶搜索技巧

### 使用正则表达式

在全局搜索中启用正则模式后，可以查找特定格式内容：

```markdown
\d+
[\w.-]+@[\w.-]+\.\w+
```

### 在结果中快速预览

- `Enter`：打开目标笔记
- `Ctrl/Cmd + Enter`：在新标签页打开
- 鼠标悬停：查看搜索结果上下文
- 搜索结果页支持连续查看上下文，适合快速判断一条命中是否真的是目标内容

### 配合命名规范使用

统一文件命名、标签命名和属性字段后，搜索效率会明显提高。

## 六、推荐工作流

1. 先用链接把相关主题连接起来
2. 再用搜索检查是否存在重复主题、缺失页面或孤立内容
3. 对高频搜索结果建立索引页或总览页
