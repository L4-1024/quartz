# 快速上手 6：图片越来越多后，附件管理怎么做才不乱

![[assets-management.png|附件与图片管理封面]]

> 适读人群：经常在笔记中插图、粘贴截图或存放附件的读者
> 
> 阅读收获：建立稳定的附件目录与图片嵌入规范

## 问题场景

![[attachment-rules.png|附件命名与归档规则]]

截图越贴越多，文件夹越来越乱？当你开始在笔记中插入图片、附件时，如果没有良好的管理习惯，久而久之就会出现：
- 图片散落在各个笔记目录下
- 同一张图片被复制多份
- 附件和笔记名称混乱对应

Obsidian 自带两个附件管理设置，让你的图片永远井然有序。

---

## 附件管理的核心概念

### 附件是什么？

在 Obsidian 中，附件包括：
- 图片：`PNG`、`JPG`、`GIF`、`SVG`、`WebP` 等
- 文档：`PDF`、`DOCX`、`XLSX` 等
- 音视频：`MP3`、`MP4`、`WAV` 等
- 其他任意文件

### 附件与笔记的关系

Obsidian 中的附件是独立文件，存储在保险库（Vault）文件夹内，通过链接方式嵌入笔记。

---

## 基础配置：自动管理附件

### 打开设置

`设置 → 文件与链接 → 附件`

### 核心配置项

#### 1. 附件默认存放位置

| 选项 | 说明 |
|------|------|
| 在保险库根目录的子文件夹 | 所有附件集中在 `assets/` 文件夹 |
| 在当前文件所在文件夹 | 附件与笔记放在同一目录 |

**推荐配置：**

```yaml
附件文件夹: assets
```

这样附件统一存放在 `vault/assets/` 目录下。

#### 2. 自动将附件复制到保险库

**开启此选项后：**
- 粘贴图片时自动复制到附件文件夹
- 拖拽文件时自动复制到附件文件夹
- 避免附件路径指向外部位置

#### 3. 使用 Wiki-style 链接

建议开启，这样嵌入附件使用 `![[文件名]]` 语法。

## 截图粘贴的最佳实践

### 方式一：快捷键粘贴

1. 截图（`Ctrl/Cmd + Shift + S` 或其他截图工具）
2. 在笔记中 `Ctrl/Cmd + V` 粘贴
3. Obsidian 自动将图片保存到附件文件夹

### 方式二：拖拽插入

1. 从文件管理器拖拽图片
2. 放置到笔记编辑区
3. 自动复制并插入链接

### 方式三：使用命令面板

1. `Ctrl/Cmd + P` 打开命令面板
2. 输入"插入图片"
3. 选择文件

## 附件文件夹结构建议

![[attachment-folder-structure.png|附件目录结构示意]]

### 推荐方案

```
vault/
├── assets/
│   ├── images/          # 图片
│   │   ├── screenshots/ # 截图
│   │   ├── diagrams/    # 图表
│   │   └── photos/       # 照片
│   ├── documents/        # 文档
│   │   ├── pdfs/
│   │   └── others/
│   └── audio/           # 音频
├── _templates/          # 模板
├── Daily/               # 日记
├── Notes/               # 笔记
└── .obsidian/           # 配置
```

### 在设置中指定附件文件夹

`设置 → 文件与链接 → 附件文件夹位置`

设置路径为 `assets` 或 `assets/images`

如果资料类型较多，可以统一先放在 `assets/` 下，再按图片、文档、音频继续细分。这样后续无论是迁移资料、批量清理，还是做未使用附件检查，都更容易处理。

## 图片管理技巧

### 1. 命名规范

使用有意义的文件名：

```
# 不推荐
20240115.png
截图1.png
IMG_1234.jpg

# 推荐
2024-01-15-meeting-notes.png
project-architecture-diagram.png
team-member-avatar.jpg
```

### 2. 批量重命名

选中多个文件，使用 `F2` 批量重命名。

### 3. 查找未使用的附件

使用社区插件 **Attachments Index** 或类似插件，可以列出所有未链接到笔记的附件。

### 4. 微信公众号配图管理建议

如果笔记后续要用于公众号发布，建议把封面图、正文配图、流程示意图分开存放。常见做法是将公众号相关素材集中到单独的子目录，避免和日常截图、临时图片混在一起。

## 常见问题

**Q：粘贴截图时没有自动复制到保险库？**

A：检查 `设置 → 文件与链接 → 自动将附件复制到保险库` 是否开启。

**Q：图片显示为红叉怎么办？**

A：检查图片文件是否存在于指定路径，路径是否正确。

**Q：可以更改已插入图片的存储位置吗？**

A：可以移动文件，然后更新笔记中的链接路径。
