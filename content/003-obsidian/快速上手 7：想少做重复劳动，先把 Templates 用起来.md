# 快速上手 7：想少做重复劳动，先把 Templates 用起来

![[templates-core.png|核心插件 Templates 封面]]

> 适读人群：需要提高建笔记效率的读者
> 
> 阅读收获：完成核心模板插件的启用、目录设置与基础模板配置

## 核心插件 vs 社区插件

![[template-basics.png|模板基础工作流示意]]

新用户常见的问题之一，是在尚未建立基础流程前过早安装过多插件。首先要认清两类插件的区别：

| 类型 | 来源 | 安装方式 | 稳定性 |
|------|------|----------|--------|
| 核心插件 | Obsidian 自带 | 设置中启用 | 高 |
| 社区插件 | 第三方开发 | 插件市场安装 | 参差不齐 |

建议新手先用好核心插件，再考虑社区插件。

---

## 模板插件概述

模板（Templates）是 Obsidian 最重要的核心插件之一，它能让你：
- 快速创建结构化的新笔记
- 自动插入日期、时间、标题等信息
- 统一笔记格式和风格

---

## 启用模板插件

1. `设置 → 核心插件`
2. 找到"模板"，点击启用
3. 设置模板文件夹位置

### 配置模板文件夹

```
设置 → 模板 → 模板文件夹
```

建议创建一个 `_templates` 文件夹存放所有模板：

```
vault/
├── _templates/     # 模板文件夹
├── Daily/          # 日记
├── Notes/          # 笔记
└── .obsidian/
```

---

## 创建第一个模板

在 `_templates` 文件夹中创建模板文件。

### 基础模板：每日笔记

文件名：`每日笔记.md`

```markdown
---
created: {{date}}
tags: [日记]
---

# {{title}}

## 今日回顾

## 明日计划

## 灵感记录
```

### 会议记录模板

文件名：`会议记录.md`

```markdown
---
created: {{date}}
participants: []
tags: [会议]
---

# {{title}}

## 会议信息
- 时间：{{time}}
- 参与人：{{participants}}

## 议程
1.

## 讨论要点

## 行动项
- [ ]

## 下一步
```

### 项目笔记模板

文件名：`项目笔记.md`

```markdown
---
created: {{date}}
status: 进行中
tags: [项目]
---

# {{title}}

## 项目概述

## 目标
-

## 里程碑
- [ ]

## 资源

## 备注
```

## 模板变量详解

Obsidian 模板支持以下内置变量：

| 变量 | 说明 | 示例输出 |
|------|------|----------|
| `{{title}}` | 笔记标题 | "会议纪要" |
| `{{date}}` | 当前日期 | 2024-01-15 |
| `{{time}}` | 当前时间 | 14:30 |
| `{{yesterday}}` | 昨天日期 | 2024-01-14 |
| `{{tomorrow}}` | 明天日期 | 2024-01-16 |
| `{{filename}}` | 文件名（不含扩展名） | "2024-01-15" |

### 自定义日期格式

```markdown
{{date:YYYY-MM-DD}}      → 2024-01-15
{{date:YYYY年MM月DD日}}   → 2024年01月15日
{{date:HH:mm}}           → 14:30
{{time:HHmmss}}          → 143045
```

## 使用模板创建笔记

### 方式一：命令面板

1. `Ctrl/Cmd + P` 打开命令面板
2. 输入"模板"
3. 选择"插入模板"
4. 选择目标模板

### 方式二：快捷键

设置 → 模板 → 设置快捷键（如 `Ctrl/Cmd + T`）

### 方式三：每日笔记命令

1. `Ctrl/Cmd + P`
2. 输入"新建每日笔记"
3. 自动使用默认模板创建当日日记

## 高级模板技巧

### 1. 条件内容

```markdown
---
type: daily
---

# {{title}}

{{if @tag(工作)}}
## 工作任务
- [ ]
{{end}}

{{if @tag(学习)}}
## 学习计划
- [ ]
{{end}}
```

### 2. 快捷输入触发

有些用户习惯用缩写触发模板：

1. 输入 `dnote` → 自动展开为每日笔记模板
2. 输入 `meeting` → 自动展开为会议记录模板

这需要社区插件如 **Templater** 或 **QuickAdd** 实现。

## 模板最佳实践

### 1. 统一命名规范

```
# 推荐
每日笔记.md
会议记录.md
项目启动.md

# 不推荐
模板1.md
new.md
note.md
```

### 2. 定期整理模板

- 每季度审视现有模板
- 删除不常用的模板
- 根据工作流优化模板结构

### 3. 模板变量使用场景

| 场景 | 推荐变量 |
|------|----------|
| 日记 | `{{date}}`, `{{title}}` |
| 会议 | `{{date}}`, `{{time}}`, `{{title}}` |
| 项目 | `{{date}}`, `{{title}}`, 自定义变量 |

## 常见问题

**Q：模板变量不生效怎么办？**

A：确保已正确启用"模板"核心插件，且光标位于模板变量位置后按 Enter。

**Q：可以创建带选择的模板吗？**

A：需要社区插件如 Templater，支持交互式模板。

**Q：每日笔记模板如何设置？**

A：设置 → 模板 → 每日笔记，选择默认模板文件。
