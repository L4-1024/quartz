## 模板系统的核心价值

![[template-layering.png|模板分层设计示意]]

模板的价值，不是把笔记管得更严，而是让你**少花力气开始写**。

好的模板系统应该：
1. **降低启动摩擦**：打开模板就开始写，不需要从空白页开始
2. **保持结构一致**：同类笔记格式统一，便于检索和回顾
3. **嵌入最佳实践**：把工作流固化到模板中

---

## 万能模板设计原则

### 1. 最小必要结构

不要过度设计，模板只包含必要的结构：

```markdown
# {{title}}

## 核心内容

## 关键要点
```

### 2. 可选区块设计

使用 YAML frontmatter 的可选字段：

```yaml
---
created: {{date}}
type: article      # article, note, draft
status: draft      # draft, in-progress, published
tags: []
---

# {{title}}
```

### 3. 统一的标签层级

```
tags: [笔记类型/具体内容]
示例：tags: [会议/产品评审]
```

## 分类模板设计

### 1. 日常笔记模板

文件名：`_daily.md`

```markdown
---
created: {{date}}
type: daily
weather:      # 可选
mood:         # 可选
tags: [日记]
---

# {{date:YYYY-MM-DD}} 日记

## 今日三件事
- [ ]

## 收获与反思

## 明日计划
- [ ]

## 随手记
```

### 2. 工作任务模板

文件名：`_task.md`

```markdown
---
created: {{date}}
due:           # 截止日期
priority:      # high, medium, low
status: todo
tags: [任务]
---

# {{title}}

## 任务描述

## 验收标准

## 执行步骤
- [ ]

## 相关笔记
- [[]]

## 备注
```

### 3. 读书/学习笔记模板

文件名：`_book.md`

```markdown
---
created: {{date}}
book: {{title}}
author:
type: 读书笔记
tags: [学习, 读书]
---

# {{book}} - 读书笔记

## 书籍信息
- 作者：
- 出版社：
- 阅读日期：

## 读后感

## 精华摘录
> "原文中印象深刻的段落"

## 实践应用
- [ ] 将书中的方法应用到实际工作中

## 相关笔记
- [[]]
```

### 4. 项目启动模板

文件名：`_project.md`

```markdown
---
created: {{date}}
project: {{title}}
status: 规划中
tags: [项目]
---

# {{title}} - 项目启动

## 项目概述

## 核心目标
1.

## 关键里程碑
- [ ] 阶段一：
- [ ] 阶段二：
- [ ] 阶段三：

## 团队成员
- 负责人：
- 参与者：

## 风险与挑战

## 下一步行动
- [ ]
```

## 模板变量进阶

### 1. 自定义变量

使用社区插件如 **Templater** 可以创建自定义变量：

```javascript
<%*
const today = tp.date.now();
const weekNum = moment(today).week();
tR += `week: ${weekNum}`;
%>
```

### 2. 条件逻辑

```markdown
<%* if (tp.file.tags.includes("重要")) { %>
## ⭐ 优先级：高
<%* } %>
```

### 3. 动态内容生成

```markdown
<%*
const file = this.app.vault.getAbstractFileByPath(tp.file.path);
const folder = file.parent.path;
tR += `文件位置：${folder}`;
%>
```

## 模板使用工作流

### 场景一：快速记录灵感

1. `Ctrl + P` → "插入模板" → "灵感笔记"
2. 填写核心内容
3. 保存，整个过程不超过 30 秒

### 场景二：系统性项目复盘

1. 创建项目笔记（项目模板）
2. 添加每日任务（任务模板）
3. 完成后生成总结（复盘模板）

### 场景三：建立知识库

1. 使用"文章笔记"模板记录学习内容
2. 用标签分类（`#技术`、`#方法论`）
3. 通过 Dataview 汇总同类笔记

## 模板系统管理

### 1. 模板索引文件

在 `_templates` 文件夹创建 `README.md`：

```markdown
# 模板索引

## 日常
- `_daily.md` - 每日日记

## 工作
- `_task.md` - 任务卡
- `_meeting.md` - 会议记录
- `_project.md` - 项目启动

## 学习
- `_book.md` - 读书笔记
- `_article.md` - 文章笔记
```

### 2. 定期优化

建议每季度审视一次模板系统：
- 合并相似模板
- 删除长期未使用的模板
- 根据工作流变化调整结构

## 进阶插件推荐

当内置模板功能不够用时，可以考虑：

| 插件 | 核心功能 |
|------|----------|
| **Templater** | 自定义函数、动态内容、模板脚本 |
| **QuickAdd** | 快速创建笔记、一键执行命令 |
| **Natural Language Dates** | 自然语言日期（如 "tomorrow", "next Monday"） |

### Templater 配置示例

1. 安装并启用 Templater
2. 设置模板文件夹为 `_templates`
3. 配置触发快捷键（如 `Ctrl/Alt + E`）

## 常见问题

**Q：模板变量和快捷键冲突怎么办？**

A：在设置中调整快捷键绑定，确保没有全局冲突。

**Q：如何让每日笔记自动关联到周/月视图？**

A：结合 Calendar 插件，每日笔记会自动出现在对应日期。

**Q：可以导出/导入模板吗？**

A：直接复制模板文件到 `_templates` 文件夹即可。
